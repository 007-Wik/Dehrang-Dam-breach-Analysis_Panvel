# Chapter 1: Storage-Elevation Analysis

This section of the analysis focuses on determining the storage capacity and elevation relationships for the Dehrang Dam. It processes survey data to calculate the capacity loss due to siltation over time.

## Objective
To calculate the Area-Elevation relationship and estimate the total volume of accumulated silt (capacity loss).

## Methodology Highlights
- **Survey Data Processing:** Analyzes grid box data recording the top and bottom elevations of the sludge layer.
- **Area-Elevation Relationship:** Calculates original and current water-spread areas at 0.2 m elevation intervals.
- **Volume Integration:** Utilizes the trapezoidal rule to calculate cumulative storage.
- **Capacity Loss Calculation:** Original cumulative volume minus the current cumulative volume.

## GEE Authentication

Notebooks 02, 03, and 05 require **Google Earth Engine** access. Follow these steps once:

1. Sign up at [earthengine.google.com](https://earthengine.google.com)
2. Create a GEE Cloud Project at [console.cloud.google.com](https://console.cloud.google.com)
3. In the notebook, replace `'your-project-id'` with your actual project ID
4. Run `ee.Authenticate()` and follow the URL to authorise

ISRIC SoilGrids (used in Notebooks 02 and 03) does **not** require authentication — it is a public WCS REST API.
